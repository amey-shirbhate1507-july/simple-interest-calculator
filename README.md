# Simple Interest Calculator

## Description

The Simple Interest Calculator is a simple web-based application that calculates
the simple interest based on the principal amount, rate of interest, and time.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time in Years

## Example

Suppose:

- Principal Amount = ₹10,000
- Rate of Interest = 5%
- Time = 2 years

Calculation:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

## Features

- Calculates Simple Interest quickly
- Simple and easy-to-use interface
- User can enter Principal Amount, Rate, and Time
- Displays the calculated Simple Interest

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the Simple Interest Calculator.
2. Enter the Principal Amount.
3. Enter the Rate of Interest.
4. Enter the Time in years.
5. Click the Calculate button.
6. The Simple Interest will be displayed.
